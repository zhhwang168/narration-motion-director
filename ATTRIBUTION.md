# Attribution and provenance

## This repository

Narration Motion Director is a custom skill developed by Henry / Tube U with Codex for narration-led tutorial and explainer production. It organizes a reusable direction workflow: meaning → visible action → timed cue plan → specific feedback → inspected revision.

The public package generalizes project identity settings and keeps Henry's conventions in an optional profile. Its examples include the original cat-and-fish tutorial workflow used during development.

## Reference inspiration

The project provenance records identify planning and screenshot-feedback ideas from Tested for Creators' [Cartoon Shorts Prompt Pack](https://claude.ai/artifact/ESd95hWpxpQsfR8jawt33e) as inspiration.

The original reference prompt files are **not distributed** in this repository. No license to those materials is granted by this project's MIT License. The reference link is attribution; access to the external artifact and its current terms are controlled by its publisher. Its contents were not available for independent web verification during this public-package preparation.

This skill does not carry over a requirement for a specific model, vertical format, cartoon style, continuously moving camera, estimated word timing or browser-recording export. Project choices and timing evidence take precedence.

## External tools

Codex, HyperFrames, Remotion, GSAP and FFmpeg are named as external products or tools. Their source, licenses and services are separate. Their skill packages, executables and media assets are not bundled here. This repository is an independent workflow project, not an official OpenAI or renderer distribution.
